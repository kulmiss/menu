1. Open **Branches**.
2. Tap **Prices & availability** on the branch.
3. Type a new price next to a dish. Leave it blank to use the main menu price.
4. Under availability choose **As main menu**, <!-- if sold_out -->**Sold out**, <!-- endif -->or **Hide**.
5. Tap **Save**. Guests at this branch see it at once.
