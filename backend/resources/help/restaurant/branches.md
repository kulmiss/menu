1. Open **Branches**. Tap **New branch**.
2. Type the **Name**, for example "Bole".
3. Check the **Web address**. It is part of the branch menu address.
4. Add the address, phone and map link.
5. Choose the **Menus shown at this branch**.
6. Tap **Save**.

The main branch opens at your restaurant's own address. To change it, open a branch and tap **Make this the main branch**.

Your plan allows {{signup_plan.branches}} branches on the {{signup_plan}} plan. See [plans](help:plans-compared).
