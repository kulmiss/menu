| | Owner | Manager | Staff |
|---|---|---|---|
| Menu, dishes, photos | ✓ | ✓ | |
| Prices | ✓ | ✓ | only if allowed |
<!-- if sold_out -->
| Sold out | ✓ | ✓ | ✓ |
<!-- endif -->
| Appearance, QR codes, branches | ✓ | ✓ | |
| Invite people | ✓ | staff only | |
| Billing and plan | ✓ | | |

- **Owners** do everything, also billing.
- **Managers** edit the menu, branches and settings, and can invite staff.
- **Staff** see the menu<!-- if sold_out --> and mark dishes sold out<!-- endif -->. Turn on **Can edit prices** to let them change prices.

To change a role, open **Team** and choose a new role next to the name.
