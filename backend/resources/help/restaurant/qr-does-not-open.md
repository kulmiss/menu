---
title: My QR code doesn't open
topic: problems
summary: Check these five things.
order: 10
pages: /admin/qr-codes
keywords: qr not working, scan, camera, broken code
---

1. **Print size:** the code must be at least 3 cm wide. Print at 100 %, not "fit to page".
2. **Paper:** shiny paper reflects light. Use matt paper.
3. **Deleted code:** if you deleted the code, the table or the branch, its copies stop working. Download the code again.
4. **Light:** scan in good light. Hold the phone 20–30 cm away.
5. **Plan ended:** if your menu is offline, the code opens a page that says so. See [When your plan ends](help:plan-ended).

Test one copy before you print many.
