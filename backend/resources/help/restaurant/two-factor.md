After your password, you also type a 6-digit code from an app on your phone.

1. Install an authenticator app, for example Google Authenticator or Microsoft Authenticator.
2. Open **Settings → Security → Two-factor sign-in**. Tap **Turn on**.
3. Type your password.
4. Scan the QR code with the authenticator app.
5. Type the 6-digit code it shows. Tap **Verify**.
6. **Save the recovery codes** somewhere safe, for example on paper. Each one lets you sign in once if you lose your phone.
