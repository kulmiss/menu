This guide is for **Super Admins**: the people who run {{site_name}}.

- **Setup** takes you from an empty server to a live site, step by step. Do it once.
- **Daily use** has one page for each part of the Super Admin panel.
- **Problems and answers** and the **Cheat sheet** are for later.

Every page of the panel has a **?** button. It opens the matching page of this guide.

The same guide is in the code (`docs/admin-guide/`) and as one PDF (`docs/admin-guide.pdf`). Technical details are in `docs/deploy.md` and `docs/security.md`.
