## Owner requests (2026-11-14, later)

| # | Question | Decision | Why |
|---|---|---|---|
| M35 | Feature switches in the app (backend #191/#192) | The app reads `features` in `/me` (plan + restaurant + global switch already combined by the server). New keys (`sold_out`, `share`, `print_materials`) count as **on unless the server says `false`**, so an older server keeps them. "Sold out" off: no Sold out tab (the address shows "turned off"), no dashboard card, no switches in Menu, the dish editor (the field isn't sent), All dishes (filter, bulk) or branch overrides; marks show as available. `print_materials` off hides Print materials; `share`, `pdf_menu`, `order_list` off hide their Appearance switches (like the web). | Same rules as the web admin; the server refuses the calls anyway (402). |
| M36 | Super Admin → Mobile app (backend #193) | `mobile/config` is read from the device at start (never waited for) and fetched again in the background at start, on every return to the app (at most every 30 s) and on "Try again". **Below the minimum version** → "Update required" with the release notes (Play in-app update; iPhone opens the App Store link). **Maintenance** → message screen for everyone except Super Admins (signed out, "Super Admin sign-in" lets them in). **App sign-in off** → message + "Open the website" (+ Sign out). The server enforces the same (426/503/403 with `mobile.*` codes, sent because the app adds `X-App-Version`); such an answer shows the screen at once even if the saved config is older, and maintenance answers are not retried. **Recommended version** → a closable "new version" line above the app (once per version). **Banner** → closable line above the app for its audience; a `/path` link opens that screen, https opens the browser. **App features**: biometric lock off hides App lock and ignores an existing lock; push off = no phone registration (inbox still works); analytics / crash reports off = Firebase collection off and their switches hidden. | Nothing here can stop the app from opening when the server is unreachable. |
